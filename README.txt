   ফোল্ডারের নাম **direct** থাকতেই হবে, কারণ ভেতরের স্কেচের নাম
   direct.ino। Arduino IDE-র নিয়ম: ফোল্ডার আর .ino-র নাম এক না
   হলে খুলবেই না। zip খুলে ফোল্ডারটার নাম বদলাবেন না।


────────────────────────────────────────────────────────────────
১. যে দুটো লাইব্রেরি ইনস্টল করতে হবে
────────────────────────────────────────────────────────────────
Arduino IDE → Tools → Manage Libraries… → খুঁজে Install:

   ১. WiFiManager          — লেখক: tzapu
                             (ফোন দিয়ে WiFi আর API key বসানোর জন্য)
   ২. RTClib               — লেখক: Adafruit
                             (DS3231 ঘড়ির জন্য)
      ↳ RTClib ইনস্টল করতে গেলে "Install all dependencies"
        চাইবে — হ্যাঁ দিন (Adafruit BusIO লাগে)।

এই দুটোই। আর কিছু লাগবে না।

⚠️ Adafruit_SSD1306, Adafruit_GFX, U8g2, U8g2_for_Adafruit_GFX,
   arduinoWebSockets, ArduinoJson — এগুলোর **একটাও লাগবে না**।
   ইচ্ছে করেই বাদ দেওয়া হয়েছে:
     · OLED-এর ড্রাইভার নিজেদের (face.cpp)। কারণ Adafruit-এর
       display() প্রতিবার পুরো ১০২৪ বাইট পাঠায় (~২৫ ms); কথার
       সাথে ঠোঁট নাড়াতে সেকেন্ডে ২০ বার ডাকলে আধ সেকেন্ড চলে
       যেত আর I2S-এর DMA খালি হয়ে কথা কেটে যেত। এখন শুধু
       ঠোঁটের ১১৩ বাইট জানালা যায় — ২.৮ ms।
     · WebSocket-ও নিজেদের (miniws.cpp)। arduinoWebSockets পুরো
       ফ্রেম RAM-এ জমা করে, আর Gemini-র অডিও ফ্রেম ৩০–৫০ KB —
       ESP32-তে টেকে না। এখন বাইট-বাই-বাইট পড়ি, ৫১২ বাইটের
       বাফারেই হয়ে যায়।
     · বাংলা লেখা আগেই ছবি করে রাখা (banglabmp.h), কারণ U8g2-র
       unifont বাংলা যুক্তাক্ষর জোড়া দিতে পারে না — "পড়ার সময়",
       "বৃহস্পতিবার", "আর্দ্রতা" সব ভেঙে যায়।

বাকি সব (WiFi, WiFiClientSecure, Wire, Preferences, driver/i2s.h,
mbedtls) ESP32 core-এর ভেতরেই আছে।

২. ESP32 core (নতুন ল্যাপটপে না থাকলে)
────────────────────────────────────────────────────────────────

"esp32 by Espressif Systems" Install।

৪. তারের হিসাব
────────────────────────────────────────────────────────────────
INMP441 মাইক          SCK 33  ·  WS 25  ·  SD 32  ·  L/R → GND
MAX98357A স্পিকার      BCLK 26 ·  LRC 27 ·  DIN 14
                       ↳ SD পিন VIN-এ, GAIN পিন GND-তে, VIN 5V-এ
OLED (SH1106 ১.৩")     SDA 21  ·  SCL 22  ·  ঠিকানা 0x3C
DS3231 ঘড়ি            SDA 21  ·  SCL 22  ·  ঠিকানা 0x68
                       ↳ OLED-এর সাথে একই দুই তার (I2C)
MPU6050 জাইরো/অ্যাক্সেল SDA 21  ·  SCL 22  ·  ঠিকানা 0x69
                       ↳ ⚠️ AD0 পিন অবশ্যই 3.3V-এ জুড়বেন (ঠিকানা 0x69 হবে)
DFPlayer Mini বাংলা    ESP32 RX2 (GPIO 16) ◄── DFPlayer TX
                       ESP32 TX2 (GPIO 17) ──► 1kΩ ──► DFPlayer RX
                       ↳ VCC 5V-এ, GND GND-তে
TTP223 টাচ ১ (মাথা)    SIG 18 (আদর/রাগ/টাইমার অন-অফ/AI কথা)
TTP223 টাচ ২ (সাইড)    SIG 19 (মোড ও সাব-মোড বদলানো)
বোর্ডের BOOT বাটন      GPIO 0   — কথা বলার সার্বজনীন ব্যাকআপ
বোর্ডের LED            GPIO 2
রিসেট বাটন (থাকলে)     GPIO 4   — ৩ সেকেন্ড চেপে ধরলে সব মুছে যায়

চারটে চেনা ভুল:
   ১. MPU6050-এর AD0 খোলা রাখলে DS3231-এর সাথে 0x68-এ ধাক্কা খাবে — AD0 3.3V-এ দিতেই হবে
   二. MAX98357A-র SD পিন খোলা রাখলে চুপ থাকে — VIN-এ দিতে হবে
   ৩. INMP441-এর L/R খোলা রাখলে ডান চ্যানেলে যায়, আওয়াজ আসে না
   ৪. স্পিকারের VIN 3.3V-এ দিলে আওয়াজ খুব কম — 5V লাগবে

৫. প্রথমবার চালু করা
────────────────────────────────────────────────────────────────
১. আপলোড করুন। Serial Monitor খুলুন — **115200 baud**।
২. পর্দায় "সেটআপ / ফোন দিয়ে জুড়ুন" দেখাবে।
৩. ফোনের WiFi-তে খুঁজুন:
      নাম      : StudyMochi-Direct
      পাসওয়ার্ড : mochi1234
   পাতাটা নিজে খুলবে; না খুললে ব্রাউজারে  192.168.4.1
৪. নিজের WiFi বাছুন, তারপর একই পাতায় Gemini API key বসান।
   চাইলে আবহাওয়ার latitude/longitude-ও (ঢাকা আগে থেকেই বসানো)।
   Save।
৫. WiFi পেলেই NTP থেকে সময় এনে DS3231-এ বসিয়ে দেবে। ব্যাটারি
   থাকলে কারেন্ট গেলেও আর হারাবে না।

⚠️ API key কোডের ভেতরে লেখা নেই, ইচ্ছে করেই। ওটা ফোনের ওই পাতা
   দিয়ে বসে আর ESP32-র NVS-এ জমা থাকে। তাই এই ফাইলগুলো কাউকে
   দিলেও key ফাঁস হয় না।

────────────────────────────────────────────────────────────────
৯. একটা জিনিস জানিয়ে রাখা দরকার
────────────────────────────────────────────────────────────────
miniws.cpp আর weather.cpp-তে setInsecure() ব্যবহার করা হয়েছে।
মানে ট্রাফিক encrypt হয়, কিন্তু সার্ভারের সার্টিফিকেট যাচাই হয় না।
নিজের WiFi-তে ঝুঁকি কম, তবে অচেনা নেটওয়ার্কে কেউ মাঝখানে বসে
পড়তে পারে (man-in-the-middle)। চাইলে Google-এর root CA বসিয়ে
যাচাই চালু করে দেওয়া যায় — বললেই করে দেব।
